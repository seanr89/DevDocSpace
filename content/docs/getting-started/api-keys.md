# API Keys

Portal API keys let scripts and CI jobs call services through the proxy without a browser session.

1. Open **Account** and click **Create key**.
2. Copy the key immediately; it is shown only once.
3. Send it in the `X-Api-Key` header.

Keys inherit the role of the user who created them and can be revoked at any time from the same page.
